# Project Documentation

## Project Name
Supply Chain Analytics Dashboard

## Tool Used
Microsoft Power BI Desktop

## Project Objective
To analyse supply chain operations and provide insights into sales, profitability, customer behaviour, shipping efficiency and delivery performance.

## Dashboard Pages
1. Executive Overview
2. Shipping & Delivery Analysis
3. Product & Customer Insights

## Key Performance Indicators
- Total Sales
- Total Orders
- Total Quantity
- Total Profit
- Average Shipping Days

## Data Preparation
Data cleaning, data type validation and preparation were performed using Power Query.

## Data Modelling
The model includes FactSupplyChain and DimProduct tables, linked using Product Card Id.

## Analysis
DAX measures and interactive visualisations were used to explore business performance.

## Deliverable
An interactive Power BI report with three dashboard pages.
