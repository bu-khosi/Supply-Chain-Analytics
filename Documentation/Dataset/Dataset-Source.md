# Dataset Source

## Dataset Name
DataCo SMART SUPPLY CHAIN FOR BIG DATA ANALYSIS

## Source
Kaggle

## Original Dataset Link
https://www.kaggle.com/datasets/shashwatwork/dataco-smart-supply-chain-for-big-data-analysis

## Dataset Files Used
- DataCoSupplyChainDataset.csv
- DescriptionDataCoSupplyChain.csv

## Purpose
The dataset was used to analyse supply chain operations, sales performance, profitability, customer behaviour, shipping and delivery performance.

## Data Preparation
The dataset was imported into Microsoft Power BI Desktop and prepared using Power Query.
